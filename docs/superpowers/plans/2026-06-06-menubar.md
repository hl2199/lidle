# Menu Bar (SwiftBar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a macOS menu bar item (via SwiftBar) that shows the tool's state and offers pause/resume + grace-period controls, driven entirely by new subcommands in the existing `clamshell-keepawake` CLI.

**Architecture:** A new read-only `menu` subcommand emits SwiftBar-formatted output (title + info + action lines); a thin generated plugin calls it on a 5s interval. Menu click-actions shell out to `sudo clamshell-keepawake pause|resume|set`, made prompt-free by an opt-in, scoped `sudoers` drop-in installed by a new `menu-setup` subcommand. Countdown math is centralized in a `remaining_seconds` helper so the title, `status`, and menu agree.

**Tech Stack:** bash, SwiftBar (xbar-compatible plugin format), `pmset`/`ioreg`/`system_profiler`, `sudoers`/`visudo`, `osascript`, `defaults`.

**Spec:** `docs/superpowers/specs/2026-06-06-menubar-design.md`

**Testing approach:** No unit-test framework in this repo. Verification per task = `bash -n` (syntax) + running the read-only subcommands (`status`, `menu`) and checking output + `visudo -cf` for generated sudoers. Root/interactive paths (`menu-setup`, `menu-remove`, `set-prompt`, the live SwiftBar item) are covered by an on-device checklist at the end, not automated.

**Commit note:** The repo owner has been doing the git commits. Commit steps below are logical checkpoints — confirm with the owner before running `git commit`, or hand them the staged changes.

- [ ] **Step 1: Add `external_count` and `remaining_seconds` helpers**

Add immediately after the `lid_state()` function:

```bash
# Count connected external displays (meaningful when the lid is shut).
external_count() {
    system_profiler SPDisplaysDataType 2>/dev/null | grep -c "Resolution:" || true
}

# Seconds until the Mac may sleep given the current state, or empty when there
# is no active countdown (clamshell+monitor, grace already elapsed, etc.).
# Mirrors the decision cmd_tick makes; read-only.
remaining_seconds() {
    local now HOLD lid idle_ns idle since_open left
    now=$(date +%s)
    HOLD=$(hold_seconds)
    lid=$(lid_state)
    if [ "$lid" = open ]; then
        idle_ns=$(ioreg -c IOHIDSystem | awk '/HIDIdleTime/ {print $NF; exit}')
        idle=$(( ${idle_ns:-0} / 1000000000 ))
        if [ -f "$OPEN_SINCE" ]; then
            since_open=$(( now - $(cat "$OPEN_SINCE") ))
            [ "$since_open" -lt "$idle" ] && idle=$since_open
        fi
        left=$(( HOLD - idle ))
        [ "$left" -gt 0 ] && echo "$left"
    elif [ "$(external_count)" -gt 0 ]; then
        :   # clamshell with monitor: no countdown
    elif [ -f "$CLOSED_SINCE" ]; then
        left=$(( HOLD - ( now - $(cat "$CLOSED_SINCE") ) ))
        [ "$left" -gt 0 ] && echo "$left"
    fi
}
```

Add after `cmd_status()` (and before `cmd_logs()`):

```bash
# Emit a SwiftBar menu: title line, then ---, then info + action lines.
# Read-only (no root). Action items shell out to sudo clamshell-keepawake ...,
# made prompt-free by the sudoers drop-in that menu-setup installs.
cmd_menu() {
    local secs paused awake

    if [ ! -f "$PLIST" ]; then
        echo "☀ –"
        echo "---"
        echo "Not installed"
        echo "Run: sudo clamshell-keepawake install"
        return 0
    fi

    [ -f "$PAUSED" ] && paused=yes || paused=no
    secs=$(remaining_seconds)
    awake=$(pmset -g 2>/dev/null | awk '/SleepDisabled/{print $2; exit}')

    # ---- Title ----
    if [ "$paused" = yes ]; then
        echo "⏸ paused"
    elif [ -n "$secs" ]; then
        echo "☀ $(fmt_dur "$secs")"
    elif [ "${awake:-0}" = 1 ]; then
        echo "☀ on"
    else
        echo "☀ off"
    fi
    echo "---"

    # ---- Info ----
    if [ "$paused" = yes ]; then
        echo "Paused"
    else
        echo "Active"
    fi
    echo "Grace period: $(awk -v s="$(hold_seconds)" 'BEGIN{printf "%g", s/3600}') h"
    if [ "$paused" = no ] && [ -n "$secs" ]; then
        echo "Sleeps in ~$(fmt_dur "$secs")"
    fi
    echo "---"

    # ---- Pause/Resume toggle ----
    if [ "$paused" = yes ]; then
        echo "Resume | bash=/usr/bin/sudo param1=$BIN param2=resume terminal=false refresh=true"
    else
        echo "Pause | bash=/usr/bin/sudo param1=$BIN param2=pause terminal=false refresh=true"
    fi

    # ---- Set grace period submenu ----
    echo "Set grace period"
    echo "--1 hour | bash=/usr/bin/sudo param1=$BIN param2=set param3=1 terminal=false refresh=true"
    echo "--2 hours | bash=/usr/bin/sudo param1=$BIN param2=set param3=2 terminal=false refresh=true"
    echo "--3 hours | bash=/usr/bin/sudo param1=$BIN param2=set param3=3 terminal=false refresh=true"
    echo "--4 hours | bash=/usr/bin/sudo param1=$BIN param2=set param3=4 terminal=false refresh=true"
    echo "--Custom… | bash=$BIN param1=set-prompt terminal=false refresh=true"
    echo "---"

    # ---- Footer ----
    echo "Open log | bash=/usr/bin/open param1=$LOG terminal=false"
    echo "Refresh | refresh=true"
}
```

}

```bash
# Write the scoped, passwordless sudoers rule for the menu's three actions.
# Validated with visudo before being moved into place (a bad sudoers file can
# break sudo system-wide).
write_sudoers() {
    local user="$1" tmp
    tmp=$(mktemp) || die "mktemp failed"
    printf '%s ALL=(root) NOPASSWD: %s pause, %s resume, %s set *\n' \
        "$user" "$BIN" "$BIN" "$BIN" > "$tmp"
    if visudo -cf "$tmp" >/dev/null 2>&1; then
        install -m 0440 -o root -g wheel "$tmp" "$SUDOERS"
        rm -f "$tmp"
    else
        rm -f "$tmp"
        die "generated sudoers content failed validation; not installing"
    fi
}

# SwiftBar's configured plugin folder, read as the target user.
swiftbar_plugin_dir() {
    sudo -u "$1" defaults read com.ameba.SwiftBar PluginDirectory 2>/dev/null
}

# Generate the thin SwiftBar plugin (calls our menu subcommand).
write_plugin() {
    local dir="$1" user="$2" path
    path="$dir/$PLUGIN_NAME"
    printf '#!/bin/bash\nexec %s menu\n' "$BIN" > "$path"
    chmod 0755 "$path"
    chown "$user" "$path"
}
```

- [ ] **Step 3: Add `cmd_menu_setup` and `cmd_menu_remove`**

Add right after the helpers from Step 2:

```bash
cmd_menu_setup() {
    need_root menu-setup
    local user="${SUDO_USER:-}" dir
    [ -n "$user" ] || die "run via sudo from your user account (need \$SUDO_USER to scope the sudoers rule)"
    [ -f "$PLIST" ] || die "install first: sudo clamshell-keepawake install"

    write_sudoers "$user"
    echo "Installed passwordless sudo rule for ${user} (pause / resume / set)."

    dir=$(swiftbar_plugin_dir "$user")
    if [ -z "$dir" ] || [ ! -d "$dir" ]; then
        echo "SwiftBar plugin folder not found."
        echo "Install SwiftBar (https://swiftbar.app), set its Plugin Folder, then re-run:"
        echo "  sudo clamshell-keepawake menu-setup"
        return 0
    fi
    write_plugin "$dir" "$user"
    sudo -u "$user" open -g "swiftbar://refreshallplugins" 2>/dev/null || true
    echo "Installed SwiftBar plugin to ${dir}/${PLUGIN_NAME}."
    echo "The clamshell-keepawake item should appear in your menu bar."
}

cmd_menu_remove() {
    need_root menu-remove
    local user="${SUDO_USER:-}" dir
    rm -f "$SUDOERS"
    if [ -n "$user" ]; then
        dir=$(swiftbar_plugin_dir "$user")
        [ -n "$dir" ] && rm -f "$dir/$PLUGIN_NAME"
        sudo -u "$user" open -g "swiftbar://refreshallplugins" 2>/dev/null || true
    fi
    echo "Removed the menu sudo rule and SwiftBar plugin."
}
```

## Menu bar (SwiftBar)

Prefer a menu bar item over the terminal? `clamshell-keepawake` ships a
[SwiftBar](https://swiftbar.app) menu that shows the current state and gives you
one-click pause/resume and grace-period controls.

1. Install SwiftBar (`brew install --cask swiftbar`) and, on first launch, pick a
   Plugin Folder.
2. Add the menu item:
   ```sh
   sudo clamshell-keepawake menu-setup
   ```

This drops a tiny SwiftBar plugin (calling `clamshell-keepawake menu`) into your
plugin folder, and installs a **scoped, passwordless `sudo` rule** so the
Pause / Resume / Set actions act instantly. The rule
(`/etc/sudoers.d/clamshell-keepawake`) lets your user run **only**
`clamshell-keepawake pause`, `resume`, and `set <hours>` without a password —
nothing else.

The menu shows:

```
☀ 2h14m
──────────────────────────────
Active
Grace period: 3 h
Sleeps in ~2h 14m
──────────────────────────────
Pause                 (toggles to Resume when paused)
Set grace period ▸ 1h / 2h / 3h / 4h / Custom…
──────────────────────────────
Open log
Refresh
```

Remove just the menu (leaving the core tool installed):

```sh
sudo clamshell-keepawake menu-remove
```

`uninstall` also removes the menu plugin and sudo rule automatically.
```
